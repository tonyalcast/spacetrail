      AI explanations

      The ✨ button asks an AI model what a file or folder is and whether deleting it is safe, only when you press it. spacetrail sends the path (your user folder shown as ~), size, dates, where it was downloaded from and the names of a few items inside a folder, never what is inside your files. Keys are stored in ~/.config/spacetrail/api-keys.json, readable only by your user.
