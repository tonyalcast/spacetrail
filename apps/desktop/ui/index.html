Let spacetrail see the whole disk

Without Full Disk Access, macOS hides some folders from spacetrail (Mail, Messages, Safari, the Trash and other apps' data), so their size is unknown. spacetrail is already listed in System Settings: just switch it on. The permission is only for spacetrail, not your terminal.

      AI explanations

      The ✨ Explain button asks an AI model what a file or folder is and whether deleting it is safe. It is only used when you press it. spacetrail sends the path (with your user folder shown as ~), size, dates, where it was downloaded from and the names of a few items inside a folder. It never sends what is inside your files. Keys are stored in your macOS Keychain.
